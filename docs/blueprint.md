# **App Name**: Softsaath

## Core Features:

- Homepage: Display hero section with logo, tagline, and CTA, featured collection, brand values, and a product preview grid.
- Product Catalog: Showcase products with filters for fit (oversized/regular) and color (beige/white/black).
- Product Page: Display detailed product information including title, description, size guide, care instructions, and purchase options.
- Collection Page: Showcase the Drop 01 collection with an introductory description and product grid.
- Contact Form: Allow users to send messages to softsaath via email using a contact form.

## Style Guidelines:

- Primary color: Light beige (#F5F5DC), representing softness and calm.
- Background color: Off-white (#FAFAFA), to provide a clean, minimal canvas.
- Accent color: Soft gray (#808080), for a gentle, subtle contrast.
- Body and headline font: 'Literata', a serif (transitional) typeface, will give a literary, slightly formal, vintage feel that will contribute to the branding as requested.
- Use lots of whitespace to create a clean, uncluttered, aesthetic feel as requested.
- Incorporate minimalistic, gentle icons to represent brand values (feelings, slow fashion, strength).
- Subtle transitions and animations on hover and page load to enhance user experience.
